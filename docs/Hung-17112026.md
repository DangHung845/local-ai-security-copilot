# Local AI Security Copilot

## Giới thiệu

Local AI Security Copilot là dự án xây dựng trợ lý AI hỗ trợ học tập và
thực hành Cybersecurity, tập trung vào **SOC / Blue Team**.

### Mục tiêu

-   Sử dụng mô hình ngôn ngữ chạy cục bộ thông qua Ollama.
-   Xây dựng backend bằng Python và FastAPI.
-   Phát triển RAG để truy xuất kiến thức từ tài liệu.
-   Hỗ trợ phân tích log và các tình huống an ninh mạng trong môi trường
    lab được cấp phép.
-   Đưa ra phân tích và đề xuất hướng xử lý; người dùng xem xét, phê
    duyệt trước khi thực hiện hành động.
-   Phát triển giao diện web để tương tác với Copilot.

### Nguyên tắc an toàn

Dự án hướng đến học tập, phòng thủ và kiểm thử trong môi trường được
phép. Các hành động có tác động lên hệ thống cần có cơ chế kiểm soát và
phê duyệt của người dùng.

## Yêu cầu môi trường

Để phát triển và chạy dự án, cần chuẩn bị:

-   Python 3.12 hoặc phiên bản tương thích với dependencies.
-   Git.
-   Ollama và model được cấu hình cho dự án.
-   Docker khi chạy các thành phần SOC lab hoặc dịch vụ phụ trợ.
-   Môi trường có GPU là tùy chọn; có thể chạy model bằng CPU nếu phần
    cứng đáp ứng.

## Cài đặt

### 1. Clone repository

``` bash
git clone https://github.com/DangHung845/local-ai-security-copilot.git
cd local-ai-security-copilot
```

### 2. Tạo Python virtual environment

``` bash
cd backend
python -m venv .venv
```

Kích hoạt môi trường ảo:

Linux / macOS:

``` bash
source .venv/bin/activate
```

Windows PowerShell:

``` powershell
.venv\Scripts\Activate.ps1
```

### 3. Cài đặt dependencies

``` bash
pip install -r requirements.txt
```

### 4. Cấu hình Ollama

Cài đặt Ollama theo hướng dẫn chính thức, tải model cần sử dụng, sau đó
cấu hình các biến môi trường cho backend.

Tạo file `.env` trong thư mục `backend/`:

``` env
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:7b
OLLAMA_TIMEOUT=120
```

Nếu Ollama không chạy cùng môi trường với backend, cập nhật
`OLLAMA_BASE_URL` thành địa chỉ API mà backend có thể truy cập.

Tạo `.env.example` để chia sẻ tên biến và giá trị mẫu. Không commit file
`.env` chứa cấu hình riêng.

## Roadmap

### Phase 1 --- Backend MVP

**Mục tiêu:** API nhận prompt, gọi model qua Ollama và trả kết quả.

Các thành phần dự kiến:

1.  `app/main.py`: khởi tạo FastAPI.
2.  `app/core/config.py`: quản lý cấu hình bằng Pydantic Settings.
3.  `app/services/ollama_service.py`: gọi Ollama API bằng HTTPX.
4.  Chat route: nhận request và trả response.
5.  Health check: kiểm tra trạng thái backend.
6.  Tests: kiểm tra schema, service và API.

### Phase 2 --- RAG

-   Nạp tài liệu vào knowledge base.
-   Chia nhỏ văn bản (chunking).
-   Tạo embeddings.
-   Lưu trữ và truy xuất vector.
-   Đưa context liên quan vào prompt.
-   Trả lời kèm nguồn tham chiếu.

### Phase 3 --- Security Analysis và Policy Engine

-   Chuẩn hóa đầu vào log và security event.
-   Xây dựng các công cụ phân tích chỉ đọc.
-   Định nghĩa policy cho các hành động được phép.
-   Yêu cầu người dùng phê duyệt trước hành động có tác động.
-   Ghi audit log cho request, kết quả phân tích và quyết định phê
    duyệt.

### Phase 4 --- SOC Lab

-   Dựng các dịch vụ lab bằng Docker.
-   Thu thập log mẫu.
-   Xây dựng tình huống phát hiện và phân tích.
-   Kiểm thử Copilot với các tình huống Blue Team.

### Phase 5 --- Frontend và Evaluation

-   Xây dựng giao diện chat.
-   Hiển thị kết quả phân tích và nguồn tham chiếu.
-   Hiển thị trạng thái phê duyệt.
-   Đo chất lượng câu trả lời, độ trễ và tài nguyên sử dụng.
-   Viết tài liệu demo và hướng dẫn sử dụng.

## Quy tắc Git và bảo mật

Trước khi commit, cần bảo đảm `.gitignore` loại trừ tối thiểu:

-   `.env` và các file chứa secrets.
-   `.venv/`.
-   `__pycache__/` và file cache.
-   Log và file tạm.
-   Model AI dung lượng lớn.
-   Dataset hoặc dữ liệu lab nhạy cảm.

Không commit API key, token, mật khẩu, thông tin cá nhân hoặc dữ liệu
thu thập từ hệ thống khi chưa được phép.
